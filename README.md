# Campus Buddy — 대화형 Fake Door 프로토타입

## 실행
프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속하거나 Cursor의 Live Server로 `index.html`을 엽니다.

## 체험 흐름
채팅에서 휴학/졸업/장학금/수강신청에 관해 질문 → 시연용 답변 → **이 답변으로 플래너 만들기** 클릭 → 할 일 화면 → 캘린더 탭 → 할 일 체크 상태가 캘린더에 반영됩니다. 새로고침해도 로컬 저장 상태가 유지됩니다.

## 주의
실제 AI 모델이나 학교 데이터베이스를 호출하지 않습니다. 키워드 기반 가상 시나리오입니다. 일정은 현재 날짜를 기준으로 만든 임의의 날짜이며 실제 학교 마감일이 아닙니다. 방문 기록 수집 코드 및 Apps Script URL은 기존 파일을 유지했습니다. 공개 배포 전에 개인정보 고지 및 공개 쓰기 엔드포인트 보안을 검토하세요. 출시 알림 이메일은 저장하지 않습니다.


## v3 업데이트
- 질문 → 가상 답변 → 통합 작업 화면에서 할 일, 준비 서류, 달력을 동시에 표시합니다.
- 할 일 체크 시 달력 완료 상태가 즉시 동기화됩니다. 서류 체크 상태도 브라우저에 저장됩니다.
- 모든 서류와 일정은 가상 예시이며 실제 학교 규정·마감일이 아닙니다.
- 방문 기록용 Apps Script 코드는 기존 버전을 유지했습니다.


## v4 변경 사항
- 질문별 가상 신청 자격 판정 시뮬레이션 (학적 상태/학년 입력)
- 서류별 가상 준비 기한 표시
- 서류 완료 체크와 캘린더 연동 및 ICS 포함
- 실제 학사 규정/신청 가능 여부를 조회하거나 판정하는 서비스가 아닙니다.
